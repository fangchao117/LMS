## 原理：LMS 自适应滤波

**Least Mean Squares（最小均方）** 是 Widrow-Hoff 1960 年提出的在线自适应滤波算法，核心思想——用过去若干个样本的线性组合预测下一个值，权重按瞬时误差做随机梯度下降更新，无需批量训练、天然适合时间序列走窗。

更新公式（NLMS，归一化版本，抗输入尺度）：
```
y(k)   = wᵀ · x(k)                        # 预测
e(k)   = d(k) − y(k)                      # 误差
w(k+1) = (1−leak)·w(k) + μ·e(k)·x(k) / (ε + ‖x(k)‖²)
```
- `x(k)`：输入向量（过去 N 根的价格/收益）
- `d(k)`：真实目标（下一根价格/收益）
- `μ`：学习率（步长），越大越灵敏、越易震荡
- `leak`：泄漏因子，让权重轻微衰减，抗漂移
- 归一化项 `‖x(k)‖²`：让步长自适应输入能量，稳定训练

在金融时间序列中，LMS 家族（包括 RLS / Kalman 滤波）常用于：
- **自适应趋势跟踪**：低滞后线性预测价格，比固定均线更灵活
- **噪声滤除**：区分信号与随机扰动
- **短期方向预测**：虽然日线收益接近随机游走（自相关弱），但趋势段的持续性仍可利用

## 本策略的实现

### 两种模式（`config.SIGNAL_MODE` 切换）

| 模式 | 预测目标 | 信号含义 | 适用场景 |
|---|---|---|---|
| `"return"` | 下一根收益 | 预测收益归一化值 | 纯自相关，日线上通常很弱 ❌ |
| `"trend"` | 下一根价格 | (预测价−现价)/现价 | 自适应趋势跟随 ✅ **推荐** |

**trend 模式逻辑**：
1. 输入向量为过去 N 根的价格（滚动归一化到均值）；
2. 用 NLMS 集成（多阶：5/10/20 抽头，捕捉不同时间尺度）预测下一根归一化价格；
3. 反归一到真实价格，`signal = (预测价 − 现价) / 现价`；
4. 信号做扩展窗 z-score 标准化 + EMA 平滑（`span=5`）降换手；
5. 对每一根 K 线，严格用"截至 T 的数据预测 T+1"，再用 T+1 真实值在线更新权重（无未来函数）。

### 多空择时

```
signal >  阈值 -> 满仓做多
signal < −阈值 -> 满仓做空
|signal| ≤ 阈值 -> 空仓
```
阈值 = 0 时为纯多空翻转；> 0 时低置信度不开仓（过滤震荡）。

| 配置 | 总收益 | 年化 | 最大回撤 | 夏普 | 收益回撤比 | 交易笔数 | 手续费 |

## 调参入口（`config.py`）

| 参数 | 作用 |
|---|---|
| `SIGNAL_MODE` | "trend"（推荐）/ "return" |
| `TREND_ORDERS` | 滤波器阶数（抽头数）；越大越平滑/滞后 |
| `TREND_MU` | NLMS 步长；越大越灵敏/越易震荡（建议 0.1 ~ 1.0） |
| `SIGNAL_SMOOTH` | EMA 平滑跨度；越大越慢/换手越低 |
| `SIGNAL_THRESHOLD` | 信号死区；0 = 纯翻转，> 0 过滤震荡（推荐 0.3 ~ 0.8） |
| `POSITION_PCT` | 仓位占比 |

## 与前面 AI 模型项目的区别

| 维度 | AI 多模型（fg_ai/） | LMS 自适应滤波（lms_quant/） |
|---|---|---|
| 方法 | 机器学习（LightGBM/Lasso/MLP） | 信号处理（自适应滤波器） |
| 输入 | 40 个量价因子 | 过去 N 根价格 |
| 训练 | 批量拟合（需训练集） | 在线更新（无需训练） |
| 优势 | 捕捉复杂非线性 | 轻量、实时、低滞后 |
| 劣势 | 吃数据、易过拟合 | 只建模线性自相关 |

两者互补：AI 适合样本充足的多因子场景；LMS 适合数据有限或需极低延迟的趋势跟随。

## 确切规则后怎么办？

1. 如果是**纯规则**（如三均线多空、突破、通道）：改 `signal_gen.py` 的 `generate()` 函数，直接用规则算信号（不走滤波器），其余不动。
2. 如果是**不同的自适应算法**（如 RLS / Kalman）：替换 `lms_filter.py` 的 `NLMS` 类，接口保持 `predict() / adapt()` 即可。
3. 如果是**混合**（规则 + 滤波）：在 `signal_gen.py` 或 `strategy.py` 里组装逻辑。
