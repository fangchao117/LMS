# fd_vib 使用说明

玻璃期货（FG）**主力合约**量化系统：因子研究、回测、盘后信号导出，以及 **VeighNa 界面版**仿真 / 实盘对接。

适用场景：投机客户始终交易当期主力，**换月必须平旧仓再开新仓**（不平移持仓）。

---

## 1. 目录结构

```
fd_vib/
├── run.py              # 主入口（IC → 挖矿 → 调参 → 回测 → 信号）
├── config.py           # 资金、手续费、三套策略 profile
├── dominant.py         # 主力换月日历、当期合约识别
├── combo.py            # 信号组合（Don 突破、因子过滤等）
├── risk_bt.py          # ATR 风控回测（含换月平仓成本）
├── bridge.py           # 复用 fg_30m 数据层
├── ic.py / mine.py     # 因子 IC 筛选与挖矿报告
├── tune.py             # 1152 组参数网格搜索
├── install_vnpy.py     # 安装 VeighNa CTA 策略
├── import_vnpy_data.py # EDB 下载 1m → 写入 VeighNa + 30m 缓存
├── vnpy/
│   └── fg_vib_strategy.py   # VeighNa 策略类 FgVibDonStrategy
└── artifacts/          # 运行产出（信号、回测、调参结果）
```

依赖同级目录：

- `fg_30m/` — 30 分钟 K 线缓存（由 1 分钟数据聚合）
- `data/` — 原始 1 分钟行情（EDB / vnpy 导出）

## 2. 环境准备

### 2.1 Python 依赖

- Python 3.10+
- pandas、numpy
- VeighNa（仅界面版仿真 / 实盘时需要）：`vnpy_ctastrategy`

### 2.2 数据准备（首次必做）

**VeighNa 没有原生 30 分钟 K 线**（只有 1m / 1h / 日线）。本项目标准做法：

1. 下载或导入 **1 分钟**数据到 VeighNa
2. 回测 / 仿真界面选 **K 线周期 = 1 分钟**
3. `FgVibDonStrategy` 内部用 `BarGenerator` **自动合成 30 分钟**

#### 免费数据源：信易 EDB（已集成）

| 周期 | 免费额度 | 说明 |
|------|----------|------|
| 日线 | 全历史 | 适合研究，不适合本策略 |
| **1 分钟** | **最近约 1 年** | 下载后本地重采样为 30m |
| 30 分钟 | 无 | 需从 1m 合成 |

文档：https://doc.shinnytech.com/edb/latest/md_server.html

#### 一键导入 VeighNa（推荐）

```powershell
cd D:\LMS\fd_vib

# 从 EDB 下载 FG609 近 1 年 1m，写入 vnpy 数据库，并更新 30m 缓存

# 若已有 data/bars_1m_FG609.parquet，仅写入 vnpy
python import_vnpy_data.py --symbol FG609 --from-cache
```

等效原生命令（`data/download_edb.py`）：

```powershell
python data/download_edb.py --symbol CZCE.FG609 --period 1m ^
  --start "2026-04-15 09:00:00" --end "2026-07-08 15:00:00" ^
  --import-vnpy --update-fg30m
```

导入后 VeighNa **CTA 回测**设置：

```

K 线周期：1 分钟        ← 不要选 1m 以外的周期
策略：    FgVibDonStrategy
```

导入后若界面仍无数据，**重启 VeighNa Studio**。

#### 仅更新 fd_vib / fg_30m 缓存（不写 vnpy）

```powershell

```

产出：`fg_30m/artifacts/bars_30m_FG609.parquet`（供 `run.py` 回测用）

#### 其他免费来源（需自行对接）

| 来源 | 说明 |
|------|------|
| **CTP + VeighNa 录制** | 仿真/实盘连 CTP，交易时段自动落 1m 到 vnpy 库 |

## 3. 日常命令

所有命令在 `fd_vib` 目录下执行：

```powershell
cd D:\LMS\fd_vib
```

| 命令 | 说明 | 耗时 |
|------|------|------|
| `python run.py --live --profile max` | **盘后信号**（最常用） | ~10 秒 |
| `python run.py --quick --profile max` | 跳过调参，回测 + 信号 | ~1 分钟 |
| `python run.py --profile max` | 完整流程（IC + 挖矿 + 调参 + 回测 + 信号） | ~8–10 分钟 |
| `python mine.py` | 仅因子挖矿报告 | 数分钟 |
| `python tune.py` | 仅参数网格搜索 | 数分钟 |
| `python install_vnpy.py` | 安装 / 更新 VeighNa 策略 | 瞬间 |

### 3.1 策略 profile

| profile | 模式 | 特点 |
|---------|------|------|
| `max`（默认） | Don38 + ATR 风控 | 收益最高，回撤较大 |
| `balanced` | Don30 + ATR 风控 | 收益略低，回撤略小 |
| `enhanced` | Don38 + 因子 / 震荡过滤 | 过滤假突破，收益较低 |

示例：

```powershell
python run.py --live --profile balanced
```

## 4. 回测说明

### 4.1 核心假设

- **K 线**：30 分钟，未复权真实价格
- **执行**：T 根 K 线收盘产生信号 → **T+1 根开盘**调仓
- **仓位**：最多净仓 2 手，初始资金 1 万
- **风控**：ATR 硬止损 3.5×、移动止损 4.0×、单笔最大亏损 6%
- **换月**：旧合约强制平仓 + 额外手续费，新合约按信号重新开仓（**不平移**）

### 4.2 换月规则

交割月为 **1 / 5 / 9** 月合约。换月日 = 交割月**前一个月 15 日**收盘后切换主力。

当前配置的主力段（见 `dominant.py` → `DOMINANT_SEGMENTS`）：

| 合约 | 主力段 |
|------|--------|
| FG509 | 2025-06-20 ~ 2025-08-14 |
| FG601 | 2025-08-15 ~ 2025-12-14 |
| FG605 | 2025-12-15 ~ 2026-04-14 |
| FG609 | 2026-04-15 ~ 2026-08-14 |

进入新主力段前，请在 `dominant.py` 追加下一段并重新 `refresh_cache`。

### 4.3 产出文件

| 文件 | 内容 |
|------|------|
| `artifacts/stats_best.json` | 全样本 / 测试段 / 分合约统计 |
| `artifacts/equity_best.csv` | 权益曲线 |
| `artifacts/tune.json` | 调参最优参数（profile=max 时读取） |
| `artifacts/factor_ic.json` | 因子 IC 筛选结果 |
| `artifacts/live_signal.json` | **盘后实盘信号** |

## 5. 盘后信号（live_signal.json）

收盘后运行：

```powershell
python run.py --live --profile max
```

输出示例字段：

```json
{
  "dominant_symbol": "FG609",
  "vt_symbol": "FG609.CZCE",
  "target_position": 1,
  "action": "做多",
  "max_lots": 2,
  "roll": {
    "days_to_roll": 36,
    "next_symbol": "FG701"
  },
  "roll_hint": "hold"
}
```

| 字段 | 含义 |
|------|------|
| `target_position` | 目标净仓：1=多，-1=空，0=空仓 |
| `action` | 中文操作建议 |
| `roll.days_to_roll` | 距离换月剩余天数 |
| `roll_hint` | 换月前 3 天且仍有持仓时会提示平仓 |

**注意**：信号基于最后一根已完成的 30m K 线；下一根 30m 开盘执行。

## 6. VeighNa 界面版对接

### 6.1 安装策略

```powershell
cd D:\LMS\fd_vib
python install_vnpy.py
```

策略会复制到 `~/.vntrader/strategies/fg_vib_strategy.py`。修改策略源码后需重新运行安装并**重启 VeighNa Studio**。

### 6.2 两种运行模式

| signal_mode | 说明 | 适用阶段 |
|-------------|------|----------|
| `json` | 读取 `artifacts/live_signal.json` | 建议先用 1–2 周验证 |
| `compute` | 策略内实时计算 Don + ATR | 验证通过后全自动 |

### 6.3 VeighNa 操作步骤

1. 打开 **VeighNa Studio** → **CTA 策略**模块  
2. 连接 **CTP 仿真**（SimNow）或实盘网关  
3. 订阅当期主力，例如 **FG609.CZCE**  
4. K 线周期设为 **1 分钟**（策略内部合成 30m，不要选 30m）  
5. 添加策略 **FgVibDonStrategy**，主要参数：

| 参数 | 推荐值 |
|------|--------|
| `vt_symbol` | `FG609.CZCE`（须与当期主力一致） |
| `fd_vib_root` | `D:\LMS\fd_vib` |
| `profile` | `max` 或 `balanced` |
| `signal_mode` | 先 `json`，后 `compute` |
| `max_lots` | `2` |

6. 初始化 → 启动策略

### 6.4 换月操作（VeighNa）

投机账户**不能**把持仓从旧合约平移到新合约，需手动：

1. **换月日**：停止旧合约上的策略实例  
2. **平掉**旧合约全部持仓  
3. 在**新主力**（如 FG701.CZCE）上**新建**策略实例  
4. 更新 `dominant.py` 的 `DOMINANT_SEGMENTS`，刷新 30m 数据  

策略会在日志中提示「合约与当期主力不一致」或「距换月 N 天」。

### 6.5 仿真 → 实盘

1. 仿真账户跑通全流程（连接、订阅、下单、止损、换月）  
2. 实盘切换为真实 CTP 网关，合约与参数保持一致  
3. 建议实盘初期仍用 `signal_mode=json`，盘后人工核对信号后再启动

|------|------|------|
| `CAPITAL` | 10000 | 回测初始资金 |

## 8. 常见问题

**Q：VeighNa 没有 30 分钟 K 线怎么办？**  
A：下载 **1 分钟**数据（`python import_vnpy_data.py`），回测选 **1m**，策略自动合成 30m。不要直接用 1m 当 30m 逻辑跑（Don38 会失真）。

**Q：报「无 FG609 数据」**  
A：运行 `fg_30m/refresh_cache.py`，确认 `bars_30m_FG609.parquet` 存在且日期覆盖主力段。

**Q：VeighNa 里找不到 FgVibDonStrategy**  
A：执行 `python install_vnpy.py` 后重启 VeighNa；在 CTA 策略列表中刷新。

**Q：JSON 模式目标仓位为 0**  
A：先运行 `python run.py --live`；检查 `live_json_path` 是否指向正确文件。

**Q：回测收益与 VeighNa 仿真不一致**  
A：常见原因包括：执行价（回测用 T+1 开盘价，VeighNa 可能用收盘价）、手续费设置、是否含换月平仓、数据缺口。先用 `signal_mode=json` 对齐方向，再切 `compute`。

**Q：如何更新因子 / 重新调参**  
A：运行完整 `python run.py`（不加 `--quick`），或分别运行 `mine.py`、`tune.py`。
